# 2026-10-30 验收记录：多光照等级测速

## 一、实验条件

| 项 | 值 |
|---|---|
| 日期 | 2026-10-30 |
| 相机 / 镜头 | MV-CU013-A0UC + MVL-HF0828M-6MPE（8 mm） |
| 镜头到桌面 | 144 cm |
| 标定板位置 | 桁架顶面（跟踪面） |
| 标定面 WD | 114.8 cm（几何 118 cm，差 2.7%） |
| 像素尺度 | 14.73（X）/ 14.77（Y） px/cm |
| 标定质量 | 88 内角点全检出，重投影 RMS **0.044 px** |
| 视野 / 测量区 | 86.9 × 69.3 cm / 76.9 × 59.3 cm |
| 曝光 / 光圈 / 增益 | 10 ms / F2.8 / 6 dB（全程不变） |
| 帧率 | 60 fps |
| 桌面 | 未铺黑布（白桌） |
| 光照等级 | L1 = **450 lx**、L2 = **350 lx**、L3 = **550 lx**（测量区中心，照度计实测） |

## 二、方法

- 每个光照等级下，小车以 **21 / 31 cm/s** 各跑 **1 次**，录 15 s；
- 稳态阶段判据（四条同时满足）：① 目标完整落在画面 ROI 内（内缩 5 cm）；
  ② `|v − v_target| / v_target ≤ 15%`；③ 连续段（检出帧号间隔 ≤3 帧）；
  ④ 持续 ≥1.0 s；
- 指标 1：稳态阶段速度相对误差 **≤ 20%**；
- 指标 2：检测失败率 **≤ 15%**（失败率 = 统计窗内未检出帧数 ÷ 统计窗总帧数）。

## 四、结论

- **6/6 全部达标**：速度相对误差最大 **1.3%**（L1·31），失败率最大 **1.5%**（L2·31），均远低于判据；
- 三个光照等级下均能稳定检出并测速，说明该光照范围内系统可用；
- 轮廓面积随条件在 11k–41k px² 之间变化（L3·31 最小），当前面积阈值 6000 px² 仍低于所有实测值；
  若以后做更暗或更快的工况，需要复核该阈值；
- 每个组合只测 1 次，未做重复性统计；光照等级按灯位定义（450 / 350 / 550 lx，非单调）。
