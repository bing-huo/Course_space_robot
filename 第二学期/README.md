# 第二学期（2026 秋）：工业相机 + 规范场地 + 分级光照

> 目标：把"手机拍 + 离线算"升级成"工业相机 + 固定机位 + 可控光照"的测量平台，
> 实测两项指标：强光下速度误差 ≤20%、检测失败率 ≤15%。

## 二、当前关键数字（2026-10-23）

| 项 | 值 |
|---|---|
| 机位 | 镜头到桌面 143 cm；标定面 WD 113.5 cm |
| 像素尺度 | 14.67 px/cm |
| 视野 / 测量区 | 87.2 × 69.7 cm / 77 × 60 cm |
| 曝光 | 10 ms / F2.8 / gain 6 dB（1~5 ms 全频闪，工作灯 100 Hz 纹波） |
| 检测目标 | 白桁架（随小车运动），MOG2 + 自适应亮度门限 |
| 稳态窗 | 1.33 s（31 cm/s） |
| 跟踪面修正 | `PLANE_SCALE = 1.1233`（等效平面比标定面低 14 cm） |
| 实测速度 | 21 → 20.92（−0.4%）；30 → 29.28（−2.4%） |

## 三、本学期主线

1. **P0 代码整顿**：时间基准、参数外置、逐帧日志、素材归档。
2. **P1 成像与标定**：支架/机位、曝光定标、内参（可选）、透视 H、尺度验证。
3. **P2 正常光基线**：`main_v2.py` 移植、MOG2 重调、L0 失败率达标。
4. **P3 光照系统**：距离分级、频闪复检、等级定义。
5. **P4 强光退化**：10 组数据、失败率统计、退化曲线。
6. **P5 交付**：报表、报告、演示。
