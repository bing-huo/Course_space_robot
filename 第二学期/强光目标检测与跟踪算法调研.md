# 强光目标检测与跟踪算法调研（整理稿）

> 来源：codex 分支《强光目标检测与跟踪算法调研》（2026-10-13），
> 结合 2026-10-23/24 现场实测整理。
> 定位：本科科创训练；固定相机、固定场地、干净背景、**单个运动目标**。

## 结论先行

> **MOG2 + 单轮廓质心 + 单应性映射 + Alpha-Beta 滤波** 是唯一主线。
> 不引入 YOLO、不贴人工标识、不做多目标跟踪。

---

## 一、四条基本判断

1. **YOLO 不适合做主路线。** 只有一个已知运动目标，场地和背景可控。先检测再跟踪会引入训练、
   检测框抖动、漏检和额外延迟，复杂度和收益不匹配。
2. **不需要给目标加标识。** 背景干净、场内只有一个运动目标，靠面积和位置范围就能排除噪声。
   标识码只作为将来做姿态/多目标区分时的扩展。
3. **强光影响相当一部分可由相机参数和布光化解。** 手动曝光、低增益、合适光圈、固定白平衡、
   稳定补光，能明显压低过曝、噪声和帧间亮度波动。
4. **已经丢失的图像信息无法靠算法恢复。** 目标饱和、强镜面反射、明显拖影、移动阴影、
   低频频闪——这些只能调曝光/光圈/灯位/遮光，而不是加算法。

本学期的任务因此是：

> 完成单目标测速算法向工业相机的迁移，建立不同光照等级下的相机参数预设，
> 验证简化前景分割在强光下的检测稳定性、测速误差和可用边界。

---

## 二、明确不做

- 不训练或部署 YOLO；
- 不做"YOLO + 跟踪器"的串联；
- 不用 ByteTrack / DeepSORT 等多目标跟踪；
- 不强制加 ArUco / AprilTag；
- 不做光照增强神经网络；
- 不追求开放环境、任意背景的通用识别。

原因不是"技术不可行"，而是**超出场景需求和本科课程的工作量**。

---

## 三、检测方法选型

### 3.1 唯一主线：MOG2 背景建模

理由：固定相机 + 干净背景 + 单目标，完全满足背景建模条件；第一学期已有可运行代码；
不需要训练数据和权重；直接输出前景轮廓便于算质心；参数少，一个学期内能调完、做完实验。

使用注意：

- 每段实验前先固定灯光和相机参数；
- 保持空场 **1~1.5 s** 让模型建立背景；
- 目标进入后不再改灯光、曝光、增益；
- 运动过程中突然开灯会造成整幅误检，不纳入本学期任务；
- 目标长时间静止会被吸收进背景（本目标持续运动，影响有限）。

### 3.2 其他差分方法的定位

- **帧差法**：只能判断"有没有动"，会得到前后两条边缘，质心随速度/帧率/阈值变化，不作正式方法；
- **固定空场背景差分**：只在 MOG2 实测失败时作为简单回退，不预先做完整对照实验。

统一口径：**MOG2 是正式算法；帧差和固定背景差分只是失败后的备用思路。**

### 3.3 实测补充（2026-10-23/24）

- **频闪**：工作灯驱动有 100 Hz 纹波，1~5 ms 曝光全部频闪，10 ms 起干净
  → 曝光锁 10 ms。详见 [`光照系统实测与工作点.md`](光照系统实测与工作点.md)。
- **阴影**：单侧强光下投影很深，MOG2 的 `detectShadows` 对这么深的影子失效，
  影子被判成前景并与目标粘连 → 加**亮度门限**（只保留"运动且够亮"的像素）解决。
  实测：无门限 18.0 cm/s，加门限 24.0 cm/s（同一段视频）。
- **光照等级**：灯无调光，用两盏灯到区域中心的**水平距离**分级。

## 四、最小可用流程

```
工业相机取流 → 灰度 → 畸变校正 / ROI → MOG2 前景提取 → 形态学 →
单轮廓筛选 → 质心(图像矩) → 单应映射 → Alpha-Beta → 速度/轨迹
```

单目标轮廓选择只需三条门控（不是复杂跟踪器）：

1. 面积落在合理范围；
2. 质心位于测量区域内；
3. 有多个候选时，选离上一帧预测位置最近的。

---

## 五、强光优先用哪些参数解决

| 参数 | 处理方式 |
|---|---|
| **曝光** | 最优先。过亮/饱和 → 缩短；拖影 → 缩短；整体过暗 → 在不产生拖影范围内加长。要求 `t_exp < T_frame`，且留传输余量 |
| **增益** | 尽量低。增益抬亮度也抬噪声，会让背景差分出散点；先调灯位/光圈/曝光，增益只作小幅补偿，且每档固定 |
| **光圈** | 短曝光仍过曝时收小；调完要复查亮度、景深、边缘清晰度和衍射（4.8 μm 像元，F# 别超过 7） |
| **自动功能** | 自动曝光、自动增益、自动白平衡一律关闭；Gamma 固定；算法用灰度图 |

自动参数会把灯光变化变成第二层不可控变量，直接毁掉实验复现性。

## 六、哪些问题不能只靠调参

| 现象 | 原因 | 优先处理 |
|---|---|---|
| 大片纯白、细节消失 | 传感器饱和 | 缩短曝光、收光圈、改强光角度 |
| 目标出现高亮斑 | 镜面反射 | 改变灯与相机夹角（入射角 ≥30°） |
| 整幅图周期性明暗 | LED PWM / 纹波 | 换稳定电源或灯具；曝光取周期整数倍 |
| 移动阴影被识别为目标 | 强光改变投影 | 改善基础灯均匀度、调灯高和方向；算法加亮度门限 |
| 强光直射镜头、雾化鬼影 | 杂散光 | 遮光罩、移灯、改俯仰角 |
| 整幅画面成为前景 | 背景与当前档位不匹配 | 重采背景、固定参数 |

工程顺序：**先保证基础灯均匀 → 避免强光直射镜头 → 固定光圈/曝光/增益 → 每档采背景 → 最后调阈值和形态学。**

## 七、曝光策略与实验公平性

- **必做：固定参数退化实验。** L0 下确定一套曝光/增益/光圈，L0–L4 全程不变，只改强光灯距离或角度，
  测系统随强光增强的性能变化和失效边界。
- **可选：失败档位恢复实验。** 只对已经明显失效的 L3/L4，缩短曝光或收光圈后重跑一次，
  展示工业相机手动参数的价值。

两类实验都关自动曝光/增益，并记录曝光、增益、光圈、灯位。

---

## 八、实验与指标

- 变量：方法固定 MOG2；光照 L0–L4；每个组合重复 ≥3 次；
- 指标：处理帧率、漏检率、伪检率、静止目标质心标准差、速度误差、有效轨迹点占比、ROI 饱和率
  （`R_sat = #(I≥250) / N_ROI`）；
- 验收：相机稳定不掉帧、灯位与参数记录完整、轨迹连续、L0–L3 漏检伪检可接受、
  给出速度误差随光照增强的曲线、明确失效边界及原因、代码与数据可复现。

> 没有高精度参考设备时，不预先承诺过高的绝对测速精度，以实测为准。

## 九、与本次实测的对照

| 调研结论 | 本次实测 | 处理 |
|---|---|---|
| 曝光优先、手动固定 | 10 ms / F2.8 / 6 dB | ✅ 已落地 |
| 低频频闪属于硬件问题 | 工作灯 100 Hz 纹波，10 ms 累加一个周期 | ✅ 锁 10 ms |
| 移动阴影要靠灯光改善 | 单侧光阴影极深，MOG2 的 detectShadows 判不出 | ✅ 加自适应亮度门限（v2） |
| 不做算法横评 | 只保留 MOG2，改进都在后处理 | ✅ 遵守 |
| 时间基准要用真实时间戳 | 硬件时间戳 10 ns/刻度已接入 | ✅ |

## 十、最终推荐

> **MOG2 + 单轮廓质心 + 单应性映射 + Alpha-Beta 滤波**

技术重点不在算法堆叠，而在：稳定取流、真实时间戳、标定与坐标映射、相机参数预设、
背景与阈值适配、强光失效边界的定量验证。
