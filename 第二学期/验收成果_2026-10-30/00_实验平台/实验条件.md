## 二、硬件条件

| 项 | 值 |
|---|---|
| 相机 | MV-CU013-A0UC（1280×1024，Bayer GB8，USB3） |
| 镜头 | MVL-HF0828M-6MPE（8 mm，F2.8） |
| 机位 | 三脚架俯拍，镜头到桌面 **144 cm** |
| 桁架 | 底 12 cm / 高 14 cm / 顶面 26 cm |
| 跟踪面 | 桁架轮廓质心（等效于桁架中下部） |
| 标定面 | 桁架顶面（标定板 Q12-200-15 放在顶面） |
| 曝光 / 光圈 / 增益 | **10 ms / F2.8 / 6 dB**（全程固定） |
| 帧率 | 60 fps |
| 桌面 | 白桌，**未铺黑布** |
| 光照 | 两盏 100 W 工作灯（可加顶灯）；L1=350 lx、L2=450 lx、L3=550 lx（测量区中心实测） |
| 小车 | 三轮滑轮车 + 白色桁架，21 / 31 cm/s 两挡 |
| 测量区 | 画面内缩 5 cm，约 76.9 × 59.3 cm |
| 采集 | 笔记本 USB3 连相机，Python + MVS SDK 录 60 fps 视频 |

## 三、说明

- 单侧强光会在桌面投下长阴影，是算法需要处理的主要干扰；
- 桌面暂为白色（后续可铺黑布进一步提高对比度）；
- 机位、对焦、桁架高度任一变化都需要重新标定。
