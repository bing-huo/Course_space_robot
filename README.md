# Course_space_robot

科研创新训练课「空间捕获机器人的设计」—— **视觉算法组**

## 一句话目标

在地面用"小车 + 随车白色桁架 + 俯视工业相机"模拟空间结构运动，把上学期"手机拍 + 离线算"
的测速系统升级成"**工业相机 + 固定机位 + 分级光照**"的测量平台，验证两项指标：

- **指标 1**：强光（L2）下稳态速度相对误差 **≤ 20%**
- **指标 2**：检测失败率 **≤ 15%**（L0–L2 判定；L3/L4 作为已知工作边界）

## 快速开始

**代码的运行根目录是 `第二学期/`**（`import config` 和 `python -m camera...` 都依赖它）：

```powershell
cd "C:\Users\binghuo\Desktop\科创课\Course_space_robot\第二学期"

python config.py                                        # 参数自检
python -m camera.camera_capture list                    # 相机枚举
python -m camera.camera_capture --exposure 10000 snap out/frame.png
python -m calibration.check_board -e 10000              # px/cm、工作距离、倾角
python -m lighting.flicker_test -e 10000 -n 100         # 频闪测试
```

录小车视频：双击 `第二学期/tools/record_15s.bat`。
第一学期回归测试：`cd 第一学期/CV` 后运行 `python main.py`（需要 GUI 点四角）。

## 三条约定

1. **物理参数只有一个来源**：几何、曝光、阈值都写在 `第二学期/config.py`，文档冲突时以它为准。
2. **改机位 = 全部标定作废**：镜头高度、对焦、测量区尺寸、跟踪面高度任一变动，都要重标并更新文档。
3. **实测覆盖设计值**：测过的写实测值和日期，没测的写"待测"，不用估算冒充结果。
