# 第一学期（2026 春）：视觉测速闭环

> 目标：用手机俯视拍摄，离线跑通"检测 → 质心 → 标定 → 测速 → 报表"的完整链路。
> 代码全部冻结在 `CV`，作为第二学期回归测试的对照物。

## 一、当时的条件

| 项 | 情况 |
|---|---|
| 相机 | 手机俯视拍摄，之后离线处理（不是实时） |
| 区域 | 180 × 60 cm，临时勾画，非固定场地 |
| 目标 | 三足滑轮小车 |
| 速度 | 21 / 31 cm/s 两档 |

## 二、算法链路

```
视频 → MOG2 背景差分 → 形态学去噪 → 最大轮廓(面积>800)
     → 图像矩质心(+h×0.3) → 四角透视(180×60) → Alpha-Beta
     → 四阶段分类 → 300 dpi 四宫格报表
```

关键参数：`history=500`、`varThreshold=50`、`detectShadows=False`、椭圆核 5×5、
瞬态 αβ = 0.85/0.35、稳态 αβ = 0.15/0.005。

## 三、结果

- 21 / 31 cm/s 两档都跑通；
- 31 cm/s 稳态相对误差约 **−3.57%**（见 `CV/Report_Final_Run_31_31.0cm_s.png`）；
- 输出标注视频与四宫格学术报表。

## 五、交给第二学期的遗留问题

1. **时间基准错误**：`curr_t = len(h_t) / real_fps`，丢帧/丢检测时时间会停住 → 速度算错。
2. **区域硬编码**：180×60 写死在代码里，换场地必须改代码。
3. **质心偏移常数**：`cy + h_box × 0.3` 是经验值，换机位即失效。
4. **标定要鼠标点击**：演示/无人值守场景不可用。
5. **无逐帧检测日志**：算不出"检测失败率"这个指标。
6. **采集不可控**：手机自动曝光/白平衡随光照变化，误差里混着"相机自己的调整"。

这六条正是第二学期 P0.3 代码整顿与 P1–P2 的起点。
