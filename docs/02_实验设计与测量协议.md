# 实验设计与测量协议

> 本文回答四件事：**场地怎么摆、光照变量怎么选、暗光能不能测、两项指标怎么算**。
> 所有参数以 `config.py` 为准；实测数据见 [`光照系统实测与工作点.md`](光照系统实测与工作点.md)。

---

## 一、场地与背景

### 1.1 现状

- 桌面为**白色**，小车为**黑色**——对比度高，MOG2 好做。
- 机位已定：镜头到桌面 120 cm，跟踪面 WD 117.4 cm，视野 89.1 × 71.6 cm。
- 正式视频里会加入**白色桁架**（模拟空间结构），检测目标仍是**小车顶面**。

### 1.2 黑色桌布：先算对比度，再决定

"铺黑布模拟太空"这个想法方向对，但有一个前提要先算清楚：**目标是黑色的**。

| 方案 | 目标 vs 背景 | 检出难度 | 备注 |
|---|---|---|---|
| 白桌（现状） | 黑 vs 白，对比强 | 最容易 | 但"不像太空" |
| **黑布 + 车顶白标记** | 白 vs 黑，对比强 | 容易 | **推荐**：同时解决标定平面问题 |
| 纯黑布（无标记） | 黑 vs 黑 | 很可能检不出 | 车和背景几乎一样暗 |
| 深灰布 | 黑 vs 灰，中等 | 可用 | 折中方案 |

**建议**：如果一定要"太空感"，铺黑布的同时在**车顶贴一块 10×10 cm 哑光白板/白标**，
把检测目标从"整车轮廓"改成"车顶标记中心"。好处有三：

1. 黑车在白色以外都难检，白标记在黑布上反而是全场最亮的；
2. 跟踪点有了明确的**物理平面**，标定板垫到同一高度即可，彻底消掉 12% 的视差误差；
3. 指标 2 的失败率统计更干净（目标是一个固定大小的块，面积判据明确）。

**代价**：算法要从"整车轮廓质心"改成"车顶标记中心"（P2 阶段一起做），工作量不大。

### 1.3 白色桁架

- **静态入画没问题**：MOG2 会把不动的桁架吸收进背景；但必须在**开始录之前**就摆好，
  录制中途推入会整块判成前景。
- **遮挡**：桁架若挡住小车路径，被挡的帧是"真失败"，要在报告里单独说明，不能算算法问题。
- **反光**：白色/金属桁架在强光下会出高光斑，建议哑光处理或避开灯的正反射角。

## 二、光照等级怎么设计

### 2.1 可用的旋钮

灯是 2 盏 100 W 工作灯、**无调光**，能动的只有几何量：

| 旋钮 | 对成像的影响 | 复现难度 |
|---|---|---|
| 灯到区域中心的**水平距离 d** | 照度 ∝ 1/d² | 低（地面贴标记即可） |
| 灯架**高度 H** | 照度 ∝ 1/r²，且改变入射角 | 中（要重新调平） |
| 照射**倾角 θ** | 照度 ∝ cosθ，同时改变眩光/阴影 | 中（角度尺） |
| 方位（在区域的哪一侧） | 改变阴影方向和逆光程度 | 中 |
| 灯数（1 / 2 盏） | 照度近似翻倍、均匀性变化 | 低 |

关键事实：**水平距离、高度、倾角不是三个独立的亮度旋钮**——它们最终都只改变
"灯到目标的距离 r"和"入射角 θ"，而 `E ∝ cosθ / r²`。同时动三个，实验就说不清
"退化是哪个因素造成的"。

### 2.2 选定：一个主变量 + 一个补充变量

**主变量（进入 L0–L4 主曲线）：两盏灯到区域中心的水平距离 d，左右对称同步移动。**

固定量：灯高 **1.2 m**、倾角 **30°（相对竖直）**、两灯分居长边两侧、灯不进入相机视野。

| 等级 | 两灯水平距离 d | 说明 |
|---|---|---|
| L0 | **2.5 m** | 最远，最暗的可测档（原"仅室内光"作废，见 §三） |
| L1 | 2.0 m | |
| L2 | **1.5 m** | 指标 1 的工作点（目标白面 200~240） |
| L3 | 1.1 m | 明显高光与阴影 |
| L4 | 0.8 m | 出现局部过曝（>250 占比 >1%） |

**补充变量（不进主曲线）：入射方位/倾角。** 只做 2 个对照条件——
"正面 30°"与"侧逆 70°"，用来说明**眩光/逆光**这类几何因素对检测的影响。
它单独成节、单独记录，不混进 L0–L4 的退化曲线，否则曲线里会有两种自变量。

### 2.3 为什么不用高度/倾角当主变量

- 调高度要重新调平灯架，复现成本高，且会连带改变 β 入射角；
- 倾角同时影响**亮度和眩光**，把它当主变量，L0→L4 的变化就解释不了；
- 水平距离用卷尺 + 地面胶带就能复现到 ±2 cm，是三个旋钮里最"干净"的一个。

### 2.4 每档必须记录

`data/conditions.csv`：等级、两灯距离/高度/倾角/方位、曝光、增益、光圈、
画面平均灰度、目标表面灰度中位数、过曝像素占比、环境光状况。**这张表是指标可复现的唯一凭据。**

## 三、暗光：能不能靠调相机参数测速

### 3.1 先分清两种"暗"

| 情况 | 有没有光 | 能不能测 |
|---|---|---|
| 只关室内灯、工作灯仍开 | 有（工作灯） | **能**，而且更可控（去掉了环境光这个混杂变量） |
| 灯也全关（全黑） | 没有光 | **不能**。没有光子，调什么参数都没用 |

所以"模拟暗光"要表述准确：**是"去掉环境光、只保留受控工作灯"，不是"全黑"。**

### 3.2 相机能补多少

三个参数可补光，合计最多约 **30 倍**：

| 参数 | 可调范围 | 相对 F5.6 / 0 dB / 10 ms 的倍率 |
|---|---|---|
| 光圈 | F5.6 → F2.8 | ×4 |
| 增益 | 0 → 16 dB | ×6.3 |
| 曝光 | 10 → 20 ms（仍是 100 Hz 的整数倍，无频闪） | ×2 |

实测参考：两灯全开、F5.6 / 10 ms 下板白面 P95 = 129；仅室内光只有 29。
按上面可以补到 29 × 30 ≈ 饱和，**亮度上完全够**。

### 3.3 代价与约束

1. **增益抬噪声**：16 dB 下暗部噪声明显，MOG2 的 `varThreshold` 要跟着调；
2. **曝光拉长 → 拖影**：20 ms 在 31 cm/s 下约 **9 px**，轮廓面积会明显缩水；
3. **参数必须全等级固定**：如果 L0 用增益 12 dB、L4 用 0 dB，曲线就混入了"相机调整"，
   结论作废。所以要么全程用一套"暗光可用"的参数，要么把暗光能力单列成一组对照实验。

**建议**：主曲线仍用 **F5.6 / 0 dB / 10 ms**；另做一组"暗光可行性"测试
（F2.8 / 12 dB / 10 ms，室内灯全关），只回答"能不能检出、失败率多少"，不并入主曲线。

## 四、采集协议

1. **空场建模**：车入镜前至少 1.5 s 开始录，开头 1.0 s 用于 MOG2 建背景。
2. **手不入画**：放车、启动都完成后开始录，避免人手/手臂被当成目标。
3. **每段 15 s**，车从画面一侧完整穿到另一侧；一段只跑一趟。
4. **10 组数据**：L0–L4 × 21/31 cm/s，每组按指标 1 的要求重复 3 次。
5. **不改相机参数**：一组实验内曝光/增益/光圈/对焦全固定；只动灯。
6. **记录条件表**：每段一行，见 §2.4。

录制命令：双击 `tools/record_15s.bat`（两盏灯、10 ms、15 s）。

## 五、指标 1：强光下速度测量精度

```
稳态区间：目标在测量区中段，且 |v(t) − v_target| / v_target ≤ 15%，最长连续段 ≥ 1.0 s
v̄ = mean(v),  相对误差 = |v̄ − v_target| / v_target × 100%
判定：L2 工况、21/31 cm/s 各 3 次取平均，≤ 20%
```

- 稳态段必须**避开起步与驶出**，否则误差虚高；
- 标定尺度误差 1:1 传导为速度误差，所以标定 1.5% 是前置条件；
- 当前状态：还没做透视标定 H，15 s 录像初步算得 **29.5 cm/s**（标称 31），
  属于"链路已通、精度待标定"。

## 六、指标 2：检测失败率

### 6.1 定义

```
失败率 = 失败帧数 / 统计窗口内总帧数 × 100%
失败帧 = 该帧没有产出有效目标位置（未检出轮廓 / 面积低于阈值 / 被判为假前景）
判定：L0、L1、L2 各 ≤ 15%；L3、L4 只报数值，作为已知工作边界
```

### 6.2 目前的问题（这一条比指标 1 更容易做错）

1. **没有逐帧日志。** `main_v2.py` 还没写，`detect_log.csv` 不存在；
   现在只能用录制视频离线算。这是 P0.3.e 的遗留项，做指标 2 前必须先补。
2. **统计窗口定义有歧义。** v2 写的是"整段视频排除开头 1.0 s"。但实际录制是
   "车入镜前 1.5 s 开录"，也就是排除 1 s 后还有 0.5 s 空场；如果按整段算，
   **空场帧没有目标，会被记成失败**，失败率凭空升高。
   **应改为：统计窗口 = 目标完整处于测量区内的那些帧**（入镜后到出画前），
   空场帧只用于建背景，不计入分母。
3. **帧率依赖。** 现在 10 ms 曝光下约 61 fps，手机是 30 fps；"按帧计数"在跨设备
   对比时不可比，需要换算成"丢失时长占比"。
4. **检出 ≠ 位置有效。** 阴影粘连会让"检出"成功但质心偏移、面积虚高。
   建议再加一条有效性判据：面积在 `[0.5, 2] × 中位数` 之外、或质心跳变超过阈值的帧，
   记为"可疑帧"单独统计，不要混进失败率。
5. **L0 还没定。** 仅室内光实测板白面只有 29，基本全黑；若 L0 这样定义，
   失败率会接近 100%，"≤15%"的基线无从谈起。必须按 §二 把 L0 改成
   "两灯最远（2.5 m）"。

### 6.3 一个实测示例

15 s 录像（两灯、10 ms）：车完整可见 **98 帧**，98 帧全部检出（面积 > 2.5 万 px²），
**窗口内失败率 0%**。但若按"整段 915 帧"做分母，失败率会变成 89%——
这就是 §6.2-2 说的窗口问题。

## 七、风险与回退

| 风险 | 触发信号 | 回退 |
|---|---|---|
| 黑布导致低对比 | 车轮廓面积明显变小/检不出 | 改深灰布，或加白标记 |
| 桁架遮挡路径 | 固定位置丢检测 | 调整桁架位置，或在报告中单列 |
| L0 太暗 | 白面灰度 <80 | 收紧灯距档位（L0 取 2.2 m）或降低曝光要求 |
| 10 ms 拖影影响面积 | 面积随速度明显下降 | 按速度分别标定阈值，报告里注明 |
| 灯温升/漂移 | 连续 1 h 灰度下滑 | 每组之间间隔开灯，记录时间 |
