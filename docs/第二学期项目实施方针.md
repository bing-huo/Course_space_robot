# 第二学期项目实施方针

> 项目：科研创新训练——空间捕获机器人视觉测量部分
> 适用阶段：第二学期实验平台搭建、工业相机适配与强光条件测试
> 当前状态：场地物资尚未到齐，方案已经完成技术收敛
> 本文件为当前实施基线；与旧文档冲突时，以本文件和后续实测修订为准。

---

## 一、核心思想

这是一个本科生科创训练项目。项目评价重点不是采用多少先进算法，而是能否围绕任务目标，完整、可靠、可复现地完成一套视觉测量系统。

因此统一遵循以下原则：

1. **任务闭环优先**：先完成场地、成像、标定、检测、跟踪、测速、实验和汇报的完整链条。
2. **使用满足需求的最简单方案**：固定相机、干净背景、单一运动目标，不引入没有必要的深度学习和多目标跟踪。
3. **先解决物理成像，再调整算法**：强光问题优先检查曝光、增益、光圈、灯位、反射和频闪。
4. **继承上学期有效成果**：第二学期以现有 MOG2、轮廓质心、单应性映射和 Alpha-Beta 滤波代码为基础。
5. **只对任务需要的内容做验证**：不做大规模算法横向评测，不为了丰富报告而增加无关工作。
6. **所有结果必须可复现**：记录相机参数、灯位、场地尺寸、标定结果、程序版本和实验条件。
7. **未实测内容必须标注为方案或预计值**：物资未到之前不把设计值写成实验结果。

一句话概括：

> 用可控场地和工业相机，把上学期的简单视觉测速流程做成一套完整、稳定、能够验证的实验系统。

## 二、任务目标与边界

### 2.1 本学期必须完成

1. 搭建固定、可重复的俯视实验场地；
2. 打通海康工业相机取流、参数控制和时间戳；
3. 完成相机内参、畸变和测量平面坐标标定；
4. 将上学期 MOG2 单目标跟踪流程适配到新相机；
5. 在基础照明和分级强光条件下完成跟踪与测速实验；
6. 给出检测稳定性、轨迹完整性和速度误差结果；
7. 说明系统的有效工作范围和强光失效边界；
8. 整理代码、配置、实验数据和报告。

### 2.2 本学期不作为主任务

- 不使用 YOLO 作为主检测方法；
- 不重新训练目标检测模型；
- 不使用 ArUco、AprilTag 等目标标识；
- 不使用 ByteTrack、DeepSORT 等多目标跟踪器；
- 不研究复杂背景和多目标遮挡；
- 不追求开放场景下的通用识别；
- 不为比较算法而额外实现多套完整系统。

### 2.3 技术问题的正确表述

本学期不是研究“哪种目标检测算法最好”，而是研究：

> 上学期的单目标视觉测速方法迁移到工业相机和新实验场地后，如何通过标定、相机参数和少量算法参数调整，实现稳定跟踪，并测试它在分级强光下的工作边界。

| 镜头 | MVL-HF0828M-6MPE | 8 mm 定焦、手动光圈 |
| 相机安装 | 独立横臂三脚架 | 不搭龙门架，相机俯视测量区 |

| 有效测量区 | 90×70 cm | 四周约留 5 cm 安全边界 |
| 理论工作距离 | 约 1.302 m | 指镜头到目标跟踪平面的距离 |

镜头离地高度不等于 1.302 m。正确关系为：

> 镜头离地高度 = 跟踪点离地高度 + 约 1.302 m

如果目标跟踪点位于机器人顶部，就必须把工作距离量到机器人顶部所在平面，而不是量到地面。

## 四、场地布置方案

### 4.1 总体布局

推荐采用“中央俯视相机、两侧对称基础灯、单侧斜射强光灯”的布局。

- 相机位于有效测量区中心正上方；
- 两盏基础灯布置在测量区长边两侧，尽量关于区域中心对称；
- 强光灯单独放在一侧，以斜入射方式照向目标运动路径；
- 相机架和灯架均放在运动区域之外；
- 强光灯不得正对镜头，避免直接产生雾化和鬼影。

### 4.2 初始安装值

以下数据只用于第一次搭建，最终值以画面直方图和现场效果修正：

| 设备 | 初始布置 |
|---|---|
| 相机 | 镜头光轴尽量垂直测量平面，覆盖 100×80 cm |
| 基础灯 A/B | 高度约 1.2～1.6 m，左右对称，俯角约 35°～45° |
| 基础灯到区域中心 | 约 0.8～1.2 m |
| 强光灯 | 高度约 1.0～1.5 m，从斜侧照向运动路径 |
| 强光灯到目标区域 | 先从约 1.5 m 开始，逐级缩短距离或改变入射方向 |

不把这些数值写成硬性标准。真正需要固定的是最终实验所采用的位置，并用卷尺、地胶带和照片记录。

### 4.3 为什么不用龙门架

独立三脚架方案可以满足当前任务，优点是成本低、搭建快、便于调整。需要重点控制的风险是晃动：

- 横臂伸出长度尽量短；
- 相机保持在三脚架重心范围内；
- 中轴不要无必要地升到极限；
- 脚架挂配重，三只脚用地胶带标记；
- 完成标定后禁止移动相机和镜头；
- 若脚架轻触后画面明显晃动，应增加配重或重新缩短横臂。

## 五、统一算法方案

### 5.1 上学期代码结论

上学期早期文件曾加载 YOLOv5 自定义权重进行识别，但最终主程序已经改为传统视觉方法。第二学期继承的是最终主程序，不是早期 YOLO 版本。

### 5.2 本学期唯一主线

> 工业相机取流 → 灰度图 → 去畸变与 ROI → MOG2 前景提取 → 形态学去噪 → 最大有效轮廓 → 轮廓质心 → 单应性映射 → Alpha-Beta 滤波 → 轨迹与速度

选择该路线的理由：

- 背景固定且干净；
- 场内只有一个运动目标；
- 上学期已有可运行代码；
- 无需训练数据和模型权重；
- 参数少，便于解释和调试；
- 足以支撑课程项目任务目标。

### 5.3 为什么不安排两种算法对照

本项目的自变量应是光照条件和相机参数，而不是算法类别。完整比较 MOG2 与固定背景差分会增加代码、调参和实验组合，但不能直接推进主要任务。

因此：

- MOG2 是唯一正式算法；
- 固定背景差分只作为 MOG2 实测失败后的备用思路；
- 不把两算法横向比较列为必做实验；
- 不为汇报内容丰富而制造额外工作量。

### 5.4 每次实验的运行条件

1. 先把基础灯和强光灯调整到本次档位；
2. 固定曝光、增益、光圈和 Gamma；
3. 画面保持空场约 1～1.5 s，使 MOG2 建立背景；
4. 目标再进入测量区；
5. 运行过程中不移动相机、灯具和场地；
6. 记录帧号、真实时间戳、质心、世界坐标和速度；
7. 实验结束后保存条件表和原始录像。

## 六、强光问题的处理原则

强光不是先靠增加算法复杂度解决，而是按以下顺序排查：

1. 是否开启了自动曝光、自动增益或自动白平衡；
2. 目标是否出现大面积饱和；
3. 曝光是否过长并产生运动模糊；
4. 增益是否过高并放大噪声；
5. 强光是否直接进入镜头；
6. 地面或目标是否出现镜面反射；
7. LED 是否存在肉眼不易察觉的 PWM 频闪；
8. 最后才调整 MOG2 阈值和形态学参数。

建议初始相机策略：

- 关闭自动曝光；
- 关闭自动增益；
- 关闭自动白平衡，或直接转灰度处理；
- 曝光从约 3～4 ms 起步，31 cm/s 条件下原则上不超过 5 ms；
- 增益从 0 dB 起步；
- 光圈从 F4 附近起步，根据亮度在 F2.8～F8 范围内调整；
- 正式实验中参数固定并完整记录。

曝光与光圈可以解决大部分可控强光问题，但不能恢复已经完全饱和的目标细节。

## 七、最小强光实验

### 7.1 光照等级

| 等级 | 基础灯 | 强光灯 | 含义 |
|---|---|---|---|
| L0 | 两盏开启 | 关闭 | 基准条件 |
| L1 | 两盏开启 | 距离较远或偏离目标 | 轻度干扰 |
| L2 | 两盏开启 | 中等距离、斜射目标区域 | 中度干扰 |
| L3 | 两盏开启 | 距离较近 | 较强干扰 |
| L4 | 两盏开启 | 可安全实现的极限位置 | 用于寻找失效边界 |

若强光灯不支持稳定调光，优先用固定功率下的距离和角度分级，避免 PWM 调光引入频闪。

### 7.2 两阶段实验

#### 必做：固定参数退化实验

- 先在 L0 确定一套可用的曝光、增益和光圈；
- L0～L4 保持相机参数不变；
- 只改变强光灯的位置或角度；
- 用来说明系统随强光增强的性能变化和失效边界。

#### 可选：参数恢复实验

只对已经明显失效的 L3 或 L4：

- 缩短曝光或收小光圈；
- 保持该新参数不变，重新运行；
- 说明工业相机参数调节能否恢复检测。

这样既保持主实验变量清晰，又能体现工业相机手动参数的价值，不需要再展开一整套算法对照。

### 7.3 最小指标

- 实际帧率和丢帧情况；
- 漏检帧比例；
- 伪检帧比例；
- 有效轨迹点占比；
- 静止目标质心抖动；
- 速度测量误差；
- ROI 内接近饱和的像素比例；
- 每档典型画面、前景掩码和轨迹图。

### 10.1 平台

- 视野能够覆盖约 100×80 cm；
- 90×70 cm 有效测量区完整位于画面中；
- 相机、镜头和脚架在实验期间不移动；
- 两盏基础灯能形成可用且基本均匀的画面；

### 10.2 标定

- Q12-200-15 参数填写正确；
- 标定图覆盖画面多个位置和倾角；
- RMS 重投影误差目标小于 0.5 px；
- 多组已知距离的尺度相对误差目标控制在 2% 以内。

### 10.3 软件

- 相机可稳定连续取流；
- 能记录帧号、时间戳和相机参数；
- MOG2 能输出连续的单目标质心；
- 像素坐标可转换为实际坐标；
- 能输出轨迹、速度和实验统计结果。

### 10.4 实验

- L0 基线实验可以稳定完成；
- L0～L4 条件记录完整；
- 至少完成多个重复试验；
- 能给出强光增强时性能变化；
- 对失效现象能区分是饱和、频闪、反射、阴影还是算法参数问题；
- 不虚构尚未获得的实验精度。

## 十一、风险与回退

| 风险 | 优先处理 | 最后回退 |
|---|---|---|
| 相机三脚架晃动 | 缩短横臂、降低中轴、加配重 | 更换更重型支架 |
| 基础光不均匀 | 调整两灯距离、高度和角度 | 加白色柔光布或反光板 |
| 强光灯频闪 | 全功率运行，以距离分级 | 更换恒流灯具 |
| 目标局部过曝 | 缩短曝光、收光圈、改灯角度 | 记录为失效边界 |
| MOG2 整幅误检 | 灯光先稳定、空场建模、提高阈值 | 再考虑固定背景差分 |
| 速度波动大 | 检查真实时间戳、标定和质心抖动 | 再调整 Alpha-Beta 参数 |
| 标定误差随位置变化 | 检查标定板覆盖和测量平面高度 | 重新标定 |

回退顺序必须遵守“硬件成像和测量链路优先，算法复杂化最后”的原则。
