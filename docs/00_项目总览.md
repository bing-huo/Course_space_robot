> 最后更新：2026-10-23 ｜ 所有物理参数以 `config.py` 为准

## 一、项目在做什么

在地面上用"三足滑轮小车 + 俯视工业相机"模拟空间在轨服务机器人的**接近段二维运动**，
用视觉系统测出小车速度，并评估它在**分级强光**下的可靠性。

太空里没有大气，光照是"直射 + 深阴影"两种极端。第二学期要做的，就是把"光照"从一个
不可控的被动条件（室内自然光），变成**可以设定、可以复现的自变量**，然后看视觉系统在哪里失效。

**一句话**：把上学期"手机拍 + 离线算"的测速流程，升级成"工业相机 + 固定机位 + 可控光照"的测量平台。

## 四、两项考核指标

| | 指标 1 | 指标 2 |
|---|---|---|
| 名称 | 强光下速度测量精度 | 检测失败率 |
| 定义 | 稳态速度相对误差 | 失败帧数 / 统计窗口内总帧数 |
| 工况 | L2 中强光，21 / 31 cm/s 各 3 次 | L0–L4 × 2 速度 = 10 组 |
| 判定 | **≤ 20%** | **L0–L2 各 ≤ 15%**；L3/L4 只报值 |
| 数据来源 | 稳态速度序列 | 逐帧检测日志 |

> 原任务书 3 项指标（多一条"直线轨迹误差 ≤5 cm"），第二学期已删，任务书待同步。
