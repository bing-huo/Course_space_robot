## 一、候选目标（来自第二学期总结）

1. **并入捕获段**：把"测量段"和"抓取段"放进同一条流程，做端到端捕获演示。
2. **多传感器融合**：视觉 + 力/位传感器，验证捕获判据。
3. **数据与仿真对齐**：和仿真组的三套工况数据做对比。

## 二、硬前提

- 并入抓取段需要更大的画面：区域约 **140 × 90 cm**（视野 150 cm、WD ≈ 1.9 m）。
- **换机位 = 全部标定作废**（镜头高度、内参、透视 H、像素尺度、跟踪面高度全要重做），
  这一步只能放在学期之间做，**不要在学期中间动**。
- 第二学期的"白桁架 + 黑底布 + 距离光照分级"方案可直接复用，但光照几何要重新标定。
