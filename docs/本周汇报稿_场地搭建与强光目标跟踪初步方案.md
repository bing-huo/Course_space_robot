# 第一部分：实验场地搭建具体方案

## 2. 场地搭建目标

场地不是普通拍摄区域，而是二维运动测量平台。它需要满足：

1. 相机能够完整覆盖运动区域；
2. 像素位置能够稳定转换为实际距离；
3. 目标运动时拖影较小；
4. 背景简单，便于前景提取；
5. 基础照明稳定，强光干扰可以单独控制；
6. 所有设备位置可以记录和复现。

---

## 3. 场地尺寸如何确定

### 3.1 已知设备

| 项目 | 参数 |
|---|---|
| 相机 | 海康机器人 MV-CU013-A0UC |
| 分辨率 | 1280×1024 |
| 快门 | 全局快门 |
| 镜头 | MVL-HF0828M-6MPE，8 mm |
| 目标速度 | 约 21 cm/s 和 31 cm/s |

### 3.2 最终尺寸

| 项目 | 设计值 |
|---|---|
| 相机视野 | 约 100×80 cm |
| 有效测量区 | 90×70 cm |
| 四周余量 | 约 5 cm |
| 镜头到跟踪平面的工作距离 | 约 1.302 m |
| 估计图像尺度 | 约 12.8 px/cm |
| 推荐铺面 | 约 160×100 cm |

采用 90×70 cm 有效测量区的原因：

- 能容纳目标的稳定运动段；
- 不要求在画面内完成完整加速过程；
- 目标可以在画面外提前进入稳定速度；
- 四周留边可减少边缘畸变和越界；
- 1280 像素覆盖 100 cm 时仍有约 12.8 px/cm 的测量分辨率。

需要强调：

> 1.302 m 是镜头到目标跟踪平面的距离，不一定是镜头到地面的距离。

## 4. 支撑结构

原方案曾考虑龙门架，现已改为三脚架方案：

| 设备 | 支撑方式 |
|---|---|
| 相机 | 一套带横臂的独立相机三脚架 |
| 基础灯 A | 一套落地灯架 |
| 基础灯 B | 一套落地灯架 |
| 强光灯 | 一套落地灯架 |

选择三脚架的原因：

- 成本更低；
- 采购和安装简单；
- 便于调整相机高度与灯光角度；
- 当前视野较小，不必搭建大型结构；
- 符合本科生科创项目的实际需求。

主要风险是相机横臂晃动，处理方式为：

- 横臂尽量短；
- 中轴不过度升高；
- 三脚架挂配重；
- 用地胶带标记脚位；
- 标定完成后不再移动相机；
- 灯架和相机架全部放在运动区之外。

## 5. 光源选型和分工

### 5.1 最终选择

| 光源 | 数量 | 用途 |
|---|---:|---|
| 公牛 50 W、6500 K LED 投光灯 | 2 | 基础照明 |
| 公牛 100 W、6500 K LED 投光灯 | 1 | 强光干扰 |
| 可调落地灯架 | 3 | 分别固定三盏灯 |

### 5.2 为什么采用两盏基础灯

单盏基础灯容易产生明显阴影和亮度梯度。两盏灯从两侧对称照明，可以：

- 改善场地整体均匀度；
- 减弱目标自身阴影；
- 给强光扰动建立稳定的基准画面；
- 减少 MOG2 把普通阴影误判为目标的概率。

### 5.3 为什么增加一盏独立强光灯

100 W 灯不承担日常补光，而是用于制造：

- 局部高亮；
- 目标表面过曝；
- 地面反光；
- 方向性阴影；
- 进入镜头附近的杂散光。

基础照明与强光扰动分开后，实验变量更清楚。

---

## 6. 灯光和相机布局

### 6.1 布局原则

- 相机位于测量区中心上方，光轴尽量垂直；
- 两盏 50 W 基础灯位于长边两侧并尽量对称；
- 100 W 强光灯从斜侧照向目标路径；
- 强光灯不得正对相机镜头；
- 各支架脚位用地胶带固定并编号。

### 6.2 第一次搭建的起始位置

| 设备 | 起始设置 |
|---|---|
| 基础灯高度 | 约 1.2～1.6 m |
| 基础灯俯角 | 约 35°～45° |
| 基础灯到区域中心 | 约 0.8～1.2 m |
| 强光灯高度 | 约 1.0～1.5 m |
| 强光灯起始距离 | 约 1.5 m，随后逐步缩短 |

以上数值不是最终实验结果。物资到达后需要依据画面亮度、均匀性、反光和饱和情况微调，并记录最终灯位。

### 6.3 推荐讲解示意

俯视关系可口头描述为：

> 相机位于区域中央上方；两盏基础灯分别位于区域左上和右上方向，对称照向中心；强光灯位于一侧中部，以斜角照向目标运动路线。相机架和三个灯架均在铺面之外。

## 7. 标定方案

### 7.1 已购标定板

| 项目 | 参数 |
|---|---|
| 型号 | Q12-200-15 |
| 外形尺寸 | 200×200 mm |
| 有效图案 | 180×135 mm |
| 单格尺寸 | 15 mm |
| 方格数量 | 12×9 |
| OpenCV 内角点 | 11×8 |

### 7.2 标定分两步

第一步：相机内参和畸变标定。

- 拍摄约 20～30 张清晰棋盘图；
- 棋盘覆盖画面中心、边缘和四角；
- 使用不同倾角；
- 对焦、光圈和分辨率在标定后保持不变。

第二步：测量平面映射。

- 在目标跟踪点所在高度建立测量平面；
- 用已知坐标点计算单应性矩阵；
- 将像素坐标转换为厘米坐标；
- 用多组已知距离独立验证。

建议目标：

- RMS 重投影误差小于 0.5 px；
- 测量平面尺度相对误差控制在 2% 以内。

# 第二部分：强光目标跟踪案例分析与初步方案

## 10. 上学期算法路线复核

上学期代码有两个阶段：

1. 早期文件曾加载自定义 YOLOv5 权重进行目标识别；
2. 最终主程序放弃 YOLO，改用 MOG2 背景建模、轮廓质心和 Alpha-Beta 滤波。

第二学期继承最终主程序：

> MOG2 前景提取 → 形态学处理 → 最大有效轮廓 → 质心 → 单应性映射 → Alpha-Beta 滤波 → 速度与轨迹

---

## 11. 为什么不继续使用 YOLO

本项目的实验条件是：

- 相机固定；
- 背景干净；
- 场内只有一个运动目标；
- 目标外观基本固定；
- 主要任务是位置和速度测量，不是类别识别。

在这种条件下，YOLO 会额外带来：

- 训练数据采集和标注；
- 模型权重管理；
- 检测框抖动；
- 漏检导致的轨迹断裂；
- 推理延迟；
- 检测框中心不一定等于目标几何中心。

因此不使用 YOLO 不是降低目标，而是根据场景选择更合适的方法。

---

## 12. 为什么不增加目标标识

ArUco 或 AprilTag 适合解决目标身份区分、姿态估计和多目标关联。本项目只有单个目标，只要求二维位置和速度。

在背景干净的条件下，通过：

- ROI 限制；
- 轮廓面积阈值；
- 最大有效轮廓；
- 与上一帧位置的简单距离限制；

即可排除大部分噪声。因此本学期不增加标识，避免增加制作、安装和强光反射问题。

---

## 13. 强光跟踪案例的共同问题

强光条件下，目标跟踪失效通常不是因为“算法不够高级”，而是图像本身发生了变化。

| 强光现象 | 图像表现 | 对跟踪的影响 |
|---|---|---|
| 目标表面饱和 | 局部或整体变成纯白 | 目标边缘消失，轮廓中心漂移 |
| 地面反光 | 出现额外亮斑 | 被 MOG2 识别成前景 |
| 方向性阴影 | 阴影随目标移动 | 阴影与目标轮廓粘连 |
| 强光直入镜头 | 整体泛白、鬼影 | 对比度下降，大面积误检 |
| LED 频闪 | 连续帧整体明暗变化 | MOG2 将整幅画面判为变化 |
| 曝光过长 | 目标边缘拖影 | 质心和速度估计发生偏移 |
| 自动曝光调整 | 每帧亮度基准变化 | 背景模型不稳定 |

这些问题说明：强光跟踪首先是成像控制问题，其次才是算法参数问题。

---

## 14. 相机参数能解决什么

工业相机的主要价值是能够手动固定成像参数。

### 14.1 曝光

- 强光过曝：缩短曝光；
- 运动拖影：缩短曝光；
- 图像过暗：在不明显拖影的前提下增加曝光。

31 cm/s、约 12.8 px/cm 时，目标图像速度约为 397 px/s：

| 曝光时间 | 理论运动模糊 |
|---:|---:|
| 1 ms | 约 0.40 px |
| 3 ms | 约 1.19 px |
| 4 ms | 约 1.59 px |
| 5 ms | 约 1.98 px |

因此初始曝光建议从 3～4 ms 开始，原则上不超过 5 ms。

### 14.2 增益

增益提高会同时放大信号和噪声。建议从 0 dB 开始，只在灯光和曝光仍不足时小幅增加。

### 14.3 光圈

- 画面过亮时收小光圈；
- 画面过暗时适当开大；
- 初始可从 F4 附近开始；
- 强光较强时可逐步收到 F5.6 或 F8。

### 14.4 自动功能

正式实验中：

- 关闭自动曝光；
- 关闭自动增益；
- 关闭自动白平衡，或直接转为灰度图；
- 固定 Gamma；
- 每段实验保存实际参数。

需要明确：

> 曝光和光圈可以减少过曝，但目标像素一旦完全饱和，软件无法恢复已经丢失的细节。

## 15. 初步算法方案

本学期只保留一条主算法：

1. 工业相机采集图像和时间戳；
2. Bayer 图像转灰度或先去马赛克再转灰度；
3. 根据标定结果去畸变；
4. 截取 90×70 cm 对应的 ROI；
5. 使用 MOG2 提取前景；
6. 进行开运算、闭运算去噪；
7. 通过面积阈值筛选轮廓；
8. 取最大有效轮廓并计算质心；
9. 将质心映射到实际坐标；
10. 使用 Alpha-Beta 滤波得到平滑轨迹和速度；
11. 保存帧号、时间戳、位置、速度和检测状态。

不安排固定背景差分与 MOG2 的完整对照。只有当 MOG2 在实际场地中确实无法满足任务时，固定背景差分才作为回退方案。

---

## 16. MOG2 在强光下的使用方式

为了避免灯光切换直接破坏背景模型，每次实验采用以下流程：

1. 先设置本次光照档位；
2. 等待灯光稳定；
3. 固定曝光、增益、光圈和 Gamma；
4. 保持空场约 1～1.5 s，使 MOG2 建立背景；
5. 再让目标进入画面；
6. 本段实验中不改变灯光和相机参数；
7. 下一档光照重新开始一次背景建模。

这样可以把研究问题限定为：

> 在每种已经稳定的光照环境下，现有算法能否完成单目标跟踪和测速。

本项目不研究“强光在目标运动过程中突然开关”的动态突变情况。

## 17. 强光分级方案

如果 100 W 强光灯没有可靠的无频闪调光功能，就采用“固定全功率、改变距离或角度”的方法。

| 等级 | 强光灯状态 | 目的 |
|---|---|---|
| L0 | 关闭 | 建立基础性能 |
| L1 | 较远、偏角 | 轻度亮度变化 |
| L2 | 中等距离、斜射 | 出现可见亮斑或阴影 |
| L3 | 较近 | 接近明显过曝 |
| L4 | 安全条件下的极限位置 | 寻找系统失效边界 |

每个档位记录：

- 强光灯距离、高度和角度；
- 曝光、增益、光圈；
- 画面平均灰度；
- 饱和像素比例；
- 目标区域亮度；
- 漏检、伪检、轨迹和速度结果。

## 18. 实验如何兼顾公平性和相机调参

为了避免把实验做得过于复杂，采用“一个必做实验加一个可选恢复实验”。

### 18.1 必做：固定相机参数

- 在 L0 下确定基准参数；
- L0～L4 均保持这套参数；
- 只改变强光条件；
- 得到性能随强光增强的退化曲线；
- 找出首次明显失效的档位。

### 18.2 可选：失败档位恢复

如果 L3 或 L4 因过曝失效：

- 缩短曝光或收小光圈；
- 重新建立背景；
- 再测试一次；
- 判断相机参数调整能否恢复跟踪。

这样既能保证主实验变量单一，也能展示工业相机手动曝光对强光问题的解决能力。

## 19. 计划评价指标

本项目不需要复杂的论文检测指标，采用与任务直接相关的指标：

| 指标 | 说明 |
|---|---|
| 实际帧率 | 相机和程序真实处理能力 |
| 丢帧数量 | FrameID 是否连续 |
| 漏检率 | 目标存在但没有输出质心的帧比例 |
| 伪检率 | 空场或噪声被输出为目标的帧比例 |
| 轨迹完整率 | 有效轨迹点占应有帧数的比例 |
| 质心抖动 | 静止目标位置的标准差 |
| 速度误差 | 与参考速度或人工测量比较 |
| 饱和像素比例 | 强光导致信息丢失的代理量 |

最终重点回答三个问题：

1. 工业相机适配后，L0 基线条件下能否稳定完成跟踪和测速？
2. 强光逐级增强时，性能如何变化？
3. 系统从哪个条件开始失效，调节曝光能否恢复？

## 24. 可能被问到的问题

### 问题一：为什么不用 YOLO？

回答：

> 因为场景固定、背景干净且只有一个目标，任务是测位置和速度，不是识别类别。YOLO 会增加训练和检测框抖动问题，上学期最终代码也已经改为 MOG2，因此本学期继续把现有方法做稳定。

### 问题二：为什么不用龙门架？

回答：

> 当前视野只有约 100×80 cm，独立横臂三脚架可以覆盖，成本和安装复杂度更低。通过缩短横臂、增加配重、固定脚位和标定后禁止移动，可以满足课程实验需要。

### 问题三：强光是否都可以靠调曝光解决？

回答：

> 曝光和光圈能解决大部分可控过曝问题，但不能恢复已经饱和的图像，也不能完全解决镜面反射、频闪和移动阴影。因此还需要控制灯位并测出系统的失效边界。

### 问题四：为什么不比较两种跟踪算法？

回答：

> 本项目目标是完成工业相机适配和强光实验，不是算法横向评测。MOG2 已经有上学期代码基础，增加第二套算法会扩大工作量，却不直接推进主要任务。只有实际测试证明 MOG2 不满足要求时才启用备用方案。

### 问题五：物资没到，这周有什么实质进展？

回答：

> 已经完成相机参数复核、场地尺寸计算、支撑与灯光方案、标定板选型、旧代码路线复核以及强光实验设计。方案收敛后，物资到达即可按固定步骤搭建和测试，减少现场反复试错。

### 问题六：如何保证速度测量可信？

回答：

> 使用全局快门降低运动形变，通过棋盘内参标定和测量平面单应性建立空间尺度，并用真实时间戳而不是简单用帧号除以标称帧率。最后用已知距离和参考速度做独立验证。
