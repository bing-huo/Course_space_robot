## 文档约定

1. **数字只有一个来源**：几何、曝光、阈值等物理参数只写在 `config.py`；文档里出现冲突时以 `config.py` 为准。
2. **实测覆盖设计值**：被测过的数（WD、px/cm、曝光、轮廓阈值）直接写实测值和日期；
   没测的写"待测"，不要用估算值冒充结果。
3. **改机位 = 全部标定作废**：镜头高度、对焦、测量区尺寸、跟踪面高度，任一项变动都要重标并更新本文档。
