## 五、文档约定

1. **数字只有一个来源**：几何、曝光、阈值等物理参数只写在 `config.py`；文档冲突时以它为准。
2. **实测覆盖设计值**：测过的直接写实测值和日期；没测的写"待测"，不用估算冒充结果。
3. **改机位 = 全部标定作废**：镜头高度、对焦、测量区尺寸、跟踪面高度任一变动，都要重标并更新文档。
4. **旧结论不删除**：被实测推翻的内容保留在原文，顶部加"已被实测取代"的标注，方便追溯决策过程。
